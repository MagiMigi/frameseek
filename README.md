# FrameSeek

A browser extension that adds a YouTube-style seek bar to videos and Reels on instagram.com, plus skip shortcuts and playback speed.

Works in Chrome, Edge, Opera and Firefox (desktop and Android) from one codebase. No build step, no dependencies, no data collection.

> Not affiliated with, endorsed by, or sponsored by Meta or Instagram.

## Install

- **Chrome:** [Chrome Web Store](https://chromewebstore.google.com/detail/frameseek-video-seek-bar/okdonibfphhnggbpfpbagfgpocgjfnhe)
- **Opera:** open the same [Chrome Web Store page](https://chromewebstore.google.com/detail/frameseek-video-seek-bar/okdonibfphhnggbpfpbagfgpocgjfnhe) in Opera and click **Add to Opera**.

## Features

- **Seek bar** on every Instagram video: Reels feed, single reel pages, feed posts, the post popup and stories. On stories, the story pauses while you drag and carries on after.
- Click or drag to seek. Hover shows a time preview, the current / total time and a speed button.
- **Keyboard shortcuts** for the video on screen:

  | Key | Action |
  | --- | --- |
  | `←` / `→` | Back / forward 5s (1, 2, 3, 4, 5, 10 or 15s, set in popup) |
  | `J` / `L` | Back / forward 10s |
  | `,` / `.` | Previous / next frame (pauses the video) |
  | `<` / `>` | Slower / faster |
  | `[` / `]` | Loop start / end |
  | `\` | Stop looping |

  `↑` / `↓` keep Instagram's next / previous reel, and in stories `←` / `→` keep Instagram's previous / next story (use `J` / `L` to skip there). Shortcuts are ignored while you type in comments, replies or messages.

  Frame stepping measures each video's frame rate while it plays (24, 25, 30, 60 fps…) and falls back to 30 fps until it knows. Click the video or press play to continue.
- **Playback speed**: 0.25× to 2×. Optionally kept for the next video. Off by default; turn on "Speed controls" in the popup.
- **Hold for 2×** (like YouTube): hold the left mouse button on a playing video and it plays at 2× until you let go, then goes back to your speed. A quick click still pauses. Not on stories, where holding pauses the story as before. On by default; turn off "Hold for 2×" in the popup.
- **Loop a section** (off by default; turn on "Loop" in the popup): click the A-B button once to mark the start, again to mark the end, and a third time to stop (or use `[`, `]` and `\`). The looped part is marked on the bar; drag its yellow edges to adjust it, and the video follows so you can see the exact frame. Not on stories, where a loop would stop the story from moving on.
- **Hover preview** (off by default; turn on "Hover preview" in the popup): hovering over the seek bar shows the frame at that point in a small box above the time, like YouTube, including parts you haven't watched yet. To show it, your browser loads a low-quality copy of the video from Instagram's own servers when you first hover over the bar, and lets it go a few seconds after you move away. If FrameSeek can't be sure which file is the video's, it shows the time only.
- **Settings popup**: click the toolbar icon to turn each feature on or off. Speed controls, Loop and Hover preview start off, so out of the box you get the seek bar, the shortcuts and hold for 2×.

## Try it locally

### Chrome / Edge

1. Open `chrome://extensions` (or `edge://extensions`).
2. Turn on **Developer mode**.
3. Click **Load unpacked** and pick this folder.
4. Open https://www.instagram.com/reels/.

After editing code, click the reload icon on the extension card, then reload the Instagram tab.

### Firefox

1. Open `about:debugging#/runtime/this-firefox`.
2. Click **Load Temporary Add-on…** and pick `manifest.json`.
3. Open https://www.instagram.com/reels/. If the bar doesn't appear, click the extensions (puzzle) button, then FrameSeek, and allow it on instagram.com.

## How it works

Instagram's class names are random and change often, so the extension only looks for `<video>` elements and the page layout.

- **Finding videos.** A `MutationObserver` notices new videos as you scroll.
- **Placement.** Each bar is mounted on the highest wrapper that has the same size as the video. That puts it above Instagram's invisible click overlay.
- **Clicks.** Clicks on the bar are stopped from reaching Instagram, so seeking doesn't pause or "like" the video.
- **Seeking.** It sets `video.currentTime`. Instagram streams video through Media Source, and seeking works normally.
- **Hover preview.** The video's own `blob:` source can't be shared with a second player, so the extension looks in the page's resource timing for the pieces Instagram's player fetched. Their URLs carry a label with the video's ID and length; dropping the byte range gives a file a hidden `<video>` can load whole. A file is only used once a small greyscale copy of its frame matches the real video's frame at the same moment, so a reel of the same length never shows another reel's frames.

## Scripts

```bash
npm run icons     # regenerate icons/*.png
npm run package   # build dist/frameseek-<version>.zip (and -opera.zip) for the stores
```

## Testing

- `npm run serve`, then open http://localhost:5173/test/harness.html. The page copies Instagram's layout: a click overlay that pauses, tagged-people and mute buttons, and React-style root listeners. A log on the right shows any click that "leaked" through to the fake Instagram handlers. Using the bar should log nothing.
- For stories, open http://localhost:5173/stories/test/1/. It has a story card with a reply box, previous/next click areas, press-and-hold to pause, side previews and a feed video behind the viewer.
- Then test on the real site with the unpacked extension:
  - The Reels feed while scrolling.
  - A `/reel/...` page.
  - A feed video post and the post popup.
  - Hold the mouse on a playing reel: 2× while held, and it keeps playing when you let go. A quick click still pauses.
  - Stories: drag, J / L, and check ← / → still switch stories and holding still pauses the story.
  - Hover preview (turn it on in the popup): the frame under the mouse on reels, feed posts, the post popup and stories, including parts not watched yet, and nothing extra in the Network panel while it's off.
  - Popup toggles (they apply live).

## Legal notes

- The extension only changes how the page looks in your own browser. It never saves videos, collects data or automates any action. It makes no network requests, except that the optional hover preview loads a low-quality copy of the hovered video from Instagram's own servers.
- It doesn't use Instagram's name or logo as its own name or branding. It refers to Instagram only to describe what it works with.
