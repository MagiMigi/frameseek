# ReelSeek

A browser extension that adds a YouTube-style seek bar to videos and Reels on instagram.com, plus skip shortcuts and playback speed.

Works in Chrome, Edge and Firefox (desktop and Android) from one codebase. No build step, no dependencies, no data collection.

> Not affiliated with, endorsed by, or sponsored by Meta or Instagram.

## Features

- **Seek bar** on every Instagram video: Reels feed, single reel pages, feed posts and the post popup. Stories keep their own bar.
- Click or drag to seek. Hover shows a time preview, the current / total time and a speed button.
- **Keyboard shortcuts** for the video on screen:

  | Key | Action |
  | --- | --- |
  | `←` / `→` | Back / forward 5s (1, 2, 3, 4, 5, 10 or 15s, set in popup) |
  | `J` / `L` | Back / forward 10s |
  | `,` / `.` | Previous / next frame (pauses the video) |
  | `<` / `>` | Slower / faster |

  `↑` / `↓` keep Instagram's next / previous reel. Shortcuts are ignored while you type in comments or messages.

  Frame stepping measures each video's frame rate while it plays (24, 25, 30, 60 fps…) and falls back to 30 fps until it knows. Click the video or press play to continue.
- **Playback speed**: 0.25× to 2×. Optionally kept for the next video.
- **Settings popup**: click the toolbar icon.

## Try it locally

### Chrome / Edge

1. Open `chrome://extensions` (or `edge://extensions`).
2. Turn on **Developer mode**.
3. Click **Load unpacked** and pick this folder.
4. Open https://www.instagram.com/reels/.

After editing code, click the reload icon on the extension card, then reload the Instagram tab.

### Firefox

1. Open `about:debugging#/runtime/this-firefox`.
2. Click **Load Temporary Add-on…** and pick `manifest.json`.
3. Open https://www.instagram.com/reels/. If the bar doesn't appear, click the extensions (puzzle) button, then ReelSeek, and allow it on instagram.com.

## How it works

Instagram's class names are random and change often, so the extension only looks for `<video>` elements and the page layout.

- **Finding videos.** A `MutationObserver` notices new videos as you scroll.
- **Placement.** Each bar is mounted on the highest wrapper that has the same size as the video. That puts it above Instagram's invisible click overlay.
- **Clicks.** Clicks on the bar are stopped from reaching Instagram, so seeking doesn't pause or "like" the video.
- **Seeking.** It sets `video.currentTime`. Instagram streams video through Media Source, and seeking works normally.

## Testing

- `npm run serve`, then open http://localhost:5173/test/harness.html. The page copies Instagram's layout: a click overlay that pauses, a mute button and React-style root listeners. A log on the right shows any click that "leaked" through to the fake Instagram handlers. Using the bar should log nothing.
- Then test on the real site with the unpacked extension:
  - The Reels feed while scrolling.
  - A `/reel/...` page.
  - A feed video post and the post popup.
  - Stories (no bar expected).
  - Popup toggles (they apply live).

## Publishing

See [store/listing.md](store/listing.md) for the step-by-step for each store and the text to paste. Bump `version` in `manifest.json` (and `package.json`) before every upload, then run `npm run package`.

## Legal notes

- The extension only changes how the page looks in your own browser. It never downloads videos, collects data, makes network requests or automates any action.
- It doesn't use Instagram's name or logo as its own name or branding. It refers to Instagram only to describe what it works with.
